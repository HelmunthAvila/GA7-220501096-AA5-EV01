Proyecto: API de Autenticación

Descripción
Servicio web desarrollado en PHP que permite registrar usuarios y realizar autenticación mediante un endpoint de login.

Tecnologías
- PHP
- MySQL
- JSON
- API REST
- Git / GitHub

Servicios

POST /api/register.php
Registro de usuario

POST /api/login.php
Inicio de sesión

Respuesta
JSON con estado de autenticación
